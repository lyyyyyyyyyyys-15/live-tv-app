## Features

- **beIN SPORTS** - Watch live beIN SPORTS channels directly
- **1000+ IPTV Channels** - Free channels from 28+ countries worldwide
- **Live Matches** - Live sports events with real-time updates
- **Match Notifications** - Get reminded 1 hour, 15 min, 5 min before kickoff, at halftime, and full time
- **Multi-Quality** - Choose between 1080p, 720p, 360p, 244p
- **Favorites** - Save your favorite channels for quick access
- **Search** - Find any channel instantly
- **Arabic & English** - Full language support with one-tap switching
- **6 Themes** - Dark, Light, Blue, Pink, Grey, Purple
- **Modern UI** - Clean, professional design

## Tech Stack

- **Language:** Kotlin
- **UI:** XML Layouts + ViewBinding
- **Video Player:** ExoPlayer (HLS support)
- **Networking:** Retrofit + OkHttp
- **Image Loading:** Glide
- **Ads:** Start.io SDK
- **Notifications:** WorkManager + AlarmManager
- **Architecture:** MVVM with Fragments

---

## How It Works

1. **YacineTV API** - beIN SPORTS channels are fetched from the YacineTV API with encrypted endpoints
2. **IPTV Streams** - Free IPTV channels are sourced from [iptv-org/iptv](https://github.com/iptv-org/iptv), a community-maintained open-source project
3. **Match Scheduling** - The app periodically fetches upcoming matches and schedules local notifications using AlarmManager
